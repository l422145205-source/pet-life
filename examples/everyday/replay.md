# 隔天又发了一遍小票，账会多算吗？

合成示例，实际运行 Python 工具生成；不是模型问答效果对比。

| 阶段 | 已记录支出 CNY | 新增记录 |
| --- | ---: | ---: |
| 原账本 | 209 | — |
| 加入12元逗猫棒小票 E2 | 221 | 1 |
| 另一次调用重放同一 E2 | 221 | 0 |

重放后文件字节保持一致：True。

依据是稳定记录 ID 与内容一致性校验，不是看两张小票总价一样就合并。同 ID 改价格会拒绝写入；不同的真实购买必须给不同 ID。过期的文件哈希也会阻止覆盖，Agent 需要重新读取和核对。

这次复现只证明记录合并工具的行为。照片识别、同一小票的身份判断和抽取质量取决于宿主 Agent 与原始资料，不能由此宣称“绝不重复记账”。
